所有图标随 EXE 打包，内网运行时不访问外部图片服务。以接入类型匹配图标；未配置图标或图片加载失败时显示原来的首字头像。

| 文件 | 来源 |
|---|---|
| `web/assets/agents/claude.svg` | 用户 CCU 项目的 `ccu_agent/desktop/assets/icons/capabilities/claude.svg`；Simple Icons，CC0，保留原图形和橙色 |
| `web/assets/agents/deepseek.svg` | DeepSeek 官方聊天页声明的 favicon：https://fe-static.deepseek.com/chat/favicon.svg ，2026-11-06 获取 |
| `web/assets/agents/ccu.png` | 用户项目 `D:\Project\CCU Agent\icon.png`，只缩放至 128 px |
| `web/assets/agents/matlab.svg` | 用户 CCU 项目的 `ccu_agent/desktop/assets/icons/capabilities/matlab.svg`；Devicon，MIT，保留原图形和颜色 |

腾讯 ADP 和没有已知品牌图标的自定义 Agent 保留首字头像。图标库许可保存在项目 `licenses/` 内并随包分发；第三方品牌标识的所有权不变。
